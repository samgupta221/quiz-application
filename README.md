# 🎯 Quiz Application

A Java-based Quiz Application project designed to build, test, and run as a standalone application.

## 📌 Overview

**Quiz Application** is a Java project configured using an Apache Ant build system and NetBeans project structure.

The project includes build configuration for compiling Java source code, running the application, creating a JAR file, executing tests, generating test reports, and producing Javadoc documentation.

## ✨ Features

- 🎯 Quiz application functionality
- ☕ Java-based application
- 🔨 Automated project build using Apache Ant
- ▶️ Application execution support
- 🧪 Test execution support
- 📦 JAR generation
- 🐞 Debugging support
- 📚 Javadoc generation
- 📊 JUnit test report generation

## 🛠️ Technologies Used

- **Java**
- **Apache Ant**
- **NetBeans Project Structure**
- **JUnit**
- **JAR**
